# Too Many Timers

[![Itch.io](https://img.shields.io/badge/Play_Now-Too_Many_Timers-e75952?style=for-the-badge)](https://gragonator.itch.io/too-many-timers)

<img width="1152" height="648" alt="ItchLogo" src="https://github.com/user-attachments/assets/da3dbb7c-3850-4652-be2a-3e2c3908d304" />

It starts innocently enough. Just one lonely timer, counting down. Click it before it hits zero. Simple.

Then another timer appears. Then a Simon Says pattern you need to repeat. Then a binary clock you apparently need to know how to read. Then more timers. Then all of the timers. Then everything gets faster, because of course it does.

**Too Many Timers** is a high-score hunting game about staying on top of an ever-growing pile of small, urgent problems until you inevitably lose control. There is no ending, no boss, no story. It is just you, your reflexes, and an increasing amount of timers.

Oh yeah, and a rubber duck. We call him Steve.
